# Machine Learning Notebooks

A collection of Jupyter notebooks created using Google Colab while learning and implementing concepts in Machine Learning, data analysis, and predictive modeling.

## 📚 Topics Covered

- **Python for Data Science** — fundamentals and practical exercises
- **NumPy & Pandas** — numerical computing and data manipulation
- **Exploratory Data Analysis (EDA)** — data exploration and visualization
- **Feature Engineering** — data preprocessing and feature selection
- **Scikit-learn** — machine learning algorithms and model evaluation
- **XGBoost** — gradient boosting and predictive modeling
- **Model Evaluation** — performance metrics and validation techniques

## 🚀 How to Use

1. Clone or download this repository.
2. Open any `.ipynb` notebook on GitHub to view its contents.
3. To execute a notebook, open it in [Google Colab](https://colab.research.google.com/) or run it locally using Jupyter Notebook.
4. Install the required Python libraries before running the code.
